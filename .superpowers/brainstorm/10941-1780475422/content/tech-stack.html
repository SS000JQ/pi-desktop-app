技术选型

你想用哪种方案作为桌面应用的框架？

A

Electron

成熟、稳定、Hermes Desktop 已验证的方案。React + Vite + Tailwind CSS。资源占用较高，但生态最完善。

优势

  • 最成熟的桌面框架
  • 文件系统/进程/原生 API 支持最好
  • 社区和工具链最完善

劣势

  • 包体积大
  • 内存占用较高
B

Tauri

轻量级替代方案，使用系统 WebView + Rust 后端。包体积小、内存低、安全性好。但 Rust 后端可能增加集成 Pi 的复杂度。

优势

  • 包体积极小（~5MB）
  • 内存开销低
  • Rust 后端安全性好

劣势

  • 系统 API 不如 Electron 丰富
  • 集成 Node.js 生态的工具需要额外工作
  • Plugin 生态不够成熟

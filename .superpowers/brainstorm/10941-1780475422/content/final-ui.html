界面变更点

变化 内容 场景
左侧 Files 新增入口，点击弹出项目文件树 浏览工作目录，浏览 Pi 生成的所有文件
Context chips 输入栏下方显示已附加的文件标签 看到当前有哪些文件在上下文中，随时移除
Preview Tab 预览面板顶部文件标签页，可切换/关闭 同时在多个生成文件之间来回切换查看
输入栏提示 底部提示: drag & drop / Ctrl+V paste / file:// paths 用户知道可以通过哪些方式给 Pi 提供文件
消息内附件 用户消息可显示附加的文件列表 用户看到自己发了哪些文件给 Pi
对话内文件引用 Pi 引用文件时展示可交互的文件卡片 点击 "Preview" 直接在 Preview 面板打开

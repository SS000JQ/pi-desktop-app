这是你想要的风格方向吗？

我理解的 Claude Code 桌面端特征：

  • 深色主题 — 暗色背景 + 代码高亮配色
  • 左侧窄栏 — 紧凑的会话/项目列表，不是宽大的 icon bar
  • 右上角信息栏 — 模型名称、token 计数、设置入口
  • 中间 Chat 区域 — 类终端风格的对话气泡，代码块有语法高亮
  • 底部输入栏 — 带 / 命令提示，简洁不花哨
  • 整体风格 — 专业工具感，去掉多余装饰，信息密度高

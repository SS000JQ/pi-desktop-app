关键差异分析

维度 Claude 做法 对我们的启发
预览类型 代码/HTML/SVG/Mermaid/Markdown/PDF/PPTX/XLSX + AI-powered 微应用 我们的列表基本覆盖了关键类型。AI-powered artifact 是 Claude 独有的护城河，无需追赶
多 Artifact 切换 聊天中一个 artifact 链接 → 右侧面板切换。同时开多个无限制 这是 v1 最值得加的功能 — 用户可能让 Pi 同时生成多个文件
版本回滚 每个 artifact 有历史版本，可还原 对 PPT/文档场景有用，v1 可以不加，但值得记录为 "v1.1"
片段编辑 选中 → "修改这部分" → Claude 只改选中区域 提升明显但实现复杂。v2 考虑
打开方式 自己内置 file editor pane 编辑 我们的优势 — 一键跳到 WPS/Office/VSCode 比内置编辑器更符合办公场景
持久化 内置 20MB 存储，跨会话保存 我们可以存到本地文件系统（用户的项目目录），比 Claude 的封闭存储更灵活

结论：Pi Desktop Preview Panel v1 应该补什么
